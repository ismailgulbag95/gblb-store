# 🛒 Mega Mart & Gourmet Restaurant 3D 🍕

Modern Three.js tabanlı, 3D Arcade-Idle / Tycoon ve Restoran Yönetim Oyunu.

## 🌟 Özellikler

- **🏢 3 Aşamalı Lineer Dünya Düzeni**:
  - 🛒 **Süpermarket**: Taze Ürün Reyonları, Kasa ve Müşteri Kuyruk Sistemi
  - 🌾 **Çiftlik & Fabrika Kompleksi**: Domates, Portakal, Mısır, Buğday Tarlaları, Salça/Meyve Suyu Kazanları, Tavuk Kümesi ve Taş Fırın
  - 🍕 **Gurme Restoran & Bistro**: Burger Izgarası, Pizza Fırını, Masalar ve Bahşiş Sistemi
- **🧑‍💼 Otonom Lojistik Çalışanları**:
  - Kasiyer (`CASHIER`)
  - Hasat Toplayıcı (`HARVESTER`)
  - Fabrika Besleyici (`FACTORY_FEEDER`)
  - Çiftlik Bakıcısı (`FARM_CARETAKER`)
  - Restoran Şefi (`CHEF`)
  - Restoran Garsonu (`WAITER`)
- **🧱 Katı Fizik ve Çarpışma Sistemi**: Tünelleme önleyici iteratif Circle-AABB fizik motoru.
- **🌍 Çoklu Dil Desteği**: Türkçe 🇹🇷 ve İngilizce 🇬🇧 anlık dil değişimi.
- **🛠️ Debug & Ayarlar Menüsü**: Hızlandırma, sınırsız bakiye ve optimizasyon seçenekleri.

---

## 🚀 Kurulum ve Çalıştırma

Projeyi bilgisayarınızda yerel olarak çalıştırmak için:

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda açılan adrese (`http://localhost:5173`) giderek oyunu oynayabilirsiniz.

## 📦 Production Derlemesi

```bash
npm run build
```
