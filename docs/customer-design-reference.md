# Customer reference redesign

The attached character sheet was used as visual reference, with no external assets or plugins.
Existing customer archetypes now use rounded block torsos, articulated block legs and hands,
enlarged heads, vertical dark eyes, layered hair, and long hairstyles for the basket shopper,
young woman and influencer. Reference outfits include pink shoppers, a brown senior jacket,
a dark office suit, blue/lavender teens, an orange tourist and a yellow child outfit.
Backpacks, white sneaker soles and laces, tourist hat band and glasses, shopping bag handles,
office shirt/tie and neck headphones add archetype detail. Staff geometry is preserved.

This is an approximate procedural interpretation, not an exact reconstruction. Existing
14 archetypes are retained; the reference's mother/child pair and pregnant customer are not
newly introduced. Existing carts, baskets and simulation inventory remain authoritative.

Validation: 26 character/archetype and animation tests passed; Vite production build passed.
Browser gallery inspected at /tests/fixtures/customer-design.html. Head and limb groups keep
the existing animation interfaces. User acceptance has not been recorded.
